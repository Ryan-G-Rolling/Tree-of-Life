## 当前状态

- 规则层（Member B）已完成：可编译、`-Werror` 零警告、自测全绿，报告页覆盖到第十二轮。
- 第十二轮内容：验收表由脚本生成（`make_report_table.py`）、危机按类型标定 damage、
  通过线按纪元区分（0.63 / 0.70）、新增阶段 11「超越」与 Omega Point。
- 内容：20 个物种（阶段 0–11）、34 个突变、14 个环境事件、18 层子升级；EP 上限 58。
- 经济：突变 `1.48^已拥有必需突变数 × (0.35+0.12×阶段)`，首突变 6 折；
  容量无上限，4 级起 ATP/Biomass 双币。
- 永久树 8 级（四线共 144 EP）；危机按事件期间最低人口与纪元通过线判定。
- A 的 `game / economy / save` 与 C 的 Raylib 界面尚未实现，当前只能用 `demo_b` 验证规则。
- 存档版本为 6（824 B）。
- 内容与机制在本轮之后冻结：A/C 追平之前不再新增物种、突变或事件。

## 已确定的核心

- 使用 C 语言和 Raylib 2D。
- 玩法由增量成长、主动选择突变、环境自然选择和跨轮永久成长组成。
- 单轮从原始生命开始，默认推进一条主谱系。
- `Diversification Lv.2` 允许维持一个额外物种分支，`Lv.3` 开启多物种协同。
- 玩家主动结束当前纪元并获得 Evolution Points，游戏不会强制结束本轮。
- 游戏逻辑不得依赖 Raylib，图形界面只读取状态和提交操作。

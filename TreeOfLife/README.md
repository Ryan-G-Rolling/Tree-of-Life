# Tree of Life · Member B 规则层

本目录是 B 负责的规则实现、自测与演示，不包含 Raylib，也不包含 A/C 的经济与界面代码。

## 三条命令

```powershell
# 构建 + 自测（Windows PowerShell）
./build.ps1

# 构建 + 自测 + 重新生成第四轮报告数据
./build.ps1 -Report

# 用 MSYS / WSL 时也可用 Make
make && make test
```

## 目录

| 路径 | 内容 |
| --- | --- |
| `include/` | 共享结构与 B 的公共头文件 |
| `src/` | evolution / species / environment / prestige / legacy / buffs |
| `data/balance.h` | 唯一平衡数据源 |
| `tests/test_b.c` | 规则自测（当前 26 组、92,568 项断言；支持 `--json`） |
| `demo/demo_b.c` | 控制台演示与经济桩，支持 `--csv / --batch / --batch2 / --batch3 / --explore / --sensitivity` |
| `build/` | 构建产物、实验 CSV 与报告生成脚本（不要整体删除） |

- 内容：186 个物种（阶段 0–13，14 阶各 10 条新增谱系）、204 个突变、20 条共振、
  14 个环境事件、30 层子升级、4 类随机增益因子；EP 上限 202。
- 经济：DNA 按人口 0.25 次幂产出（阶段 0–1 ×1.5），理念按人口 0.5 次幂产出；
  子升级逐层 ×3.2，洞见无上限（2000×1.9^级，每级 +2% 全产率）；
  突变 `1.45^下一步已拥有前置数 × 分段倍率(1.8/2.0/2.5) × (0.35+0.12×阶段)`，
  首突变 6 折；阶段 8 起高阶突变额外收 ATP（收入的 45 秒，夹在 1e7–5e8）。
- 随机增益：因子每 45–90 s 刷新，点击获得 30 s ×1.2 产率、30 s 点击 ×2、
  一次性资源包，或（≥150 s 冷却）15 s ×1.5 强增益。

- 永久树为 8 级、单线成本 36 EP、四线共 144 EP。
- 验收拆为手写 `build/design.csv` 与自动 `build/observed.csv`；目标改动会让状态降级为“目标已变更”。

## 已知缺口

- `build/` 同时存放产物与报告数据源，清理时请勿删除其中的 CSV 与 `gen_*.py`。
- MinGW 不支持 ASan；需要 sanitizer 时用 WSL/LLVM 单独跑一次。
- 报告页的历史小节是各轮快照，默认值以最新一节为准。

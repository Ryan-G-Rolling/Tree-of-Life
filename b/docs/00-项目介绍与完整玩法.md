# Tree of Life · Evolution & Legacy

## 1. 项目介绍

《Tree of Life》是一款使用 C 语言和 Raylib 制作的 2D 生物进化增量游戏。玩家从原始细胞开始，通过点击和自动生产积累 ATP、生物量和 DNA，主动选择突变与物种分化路线，并让生命接受不断变化的环境筛选。

随着进化成本提高，单轮成长会逐渐放缓。玩家可以主动结束当前演化纪元，将本轮成果结算为 Evolution Points，投入代谢、突变、适应和多样性四条永久强化路线，再从原始生命开始新一轮演化。新的轮次能够更快成长、抵达更远的生命阶段，并探索上一轮没有选择的分支。

项目的核心体验保持为三部分。

| 核心 | 玩家体验 |
| --- | --- |
| Evolution | 积累资源，主动选择突变和物种分化 |
| Selection | 环境改变各物种的适应度、产出和种群变化 |
| Legacy | 主动结束纪元，用本轮成果永久强化后续轮次 |

## 2. 已冻结的设计决定

以下内容是项目基准，后续实现不得自行改成另一套玩法。

- 呈现形式为 Raylib 2D。
- 游戏体验为增量与策略结合。平时自动成长，突变、分化、危机应对和纪元结束时进行决策。
- 单轮资源为 ATP、Biomass、DNA，以及阶段 6 之后才产出的理念（Knowledge）。
- 玩家主动选择突变，环境根据物种与突变特征产生自然选择结果。
- 默认围绕一条主谱系推进，不在开局同时管理多支种群。
- `Diversification Lv.2` 解锁一个额外活跃物种槽。主谱系负责阶段推进，额外分支参与生产、环境筛选和多样性统计。
- 玩家可以随时预览纪元结算，并自主决定是否结束本轮。增长放缓只触发提示。
- Prestige 必须形成完整闭环。结算、加点、新轮重置和永久效果生效缺一不可。
- 物种图鉴、成就、历史最佳记录、EP 余额和永久强化跨轮保留。

### 2.1 原方案中已补齐的空缺

昨天的讨论确定了玩法方向，但以下细节尚未定义。本稿已经将它们补全，避免三个人的 Agent 各自作出不同解释。

| 原先未写清的地方 | 本稿采用的统一规则 |
| --- | --- |
| Biomass 与种群是否为同一个数 | 两者分开。Biomass 是可消费资源，Population 是每个物种的规模 |
| 默认一条主谱系与多样性路线如何共存 | 开局一个活跃物种，Diversification Lv.2 增加第二物种槽 |
| 额外分支是否也推进时代 | 时代只由主谱系推进，额外分支参与生产、环境和协同 |
| 突变候选能否反复打开刷新 | 不能。生成后的候选保存到状态，选择、分化或新轮开始后才清除 |
| 环境导致种群归零后怎么办 | 不强制 Game Over，主谱系保留最低可恢复种群 |
| EP 中的物种和突变如何计数 | 按本轮首次发现记录，每项一轮只计一次 |
| 何时允许购买永久强化 | 结束纪元后的 Legacy 阶段，不能在本轮中途购买 |
| 读档能否重复领取 EP | 不能。奖励领取状态与 EP 入账一起保存 |
| 哪些内容以后可以调 | 只调数值和内容数量，不改核心循环、状态流和模块边界 |

## 3. 一轮游戏的完整流程

```text
原始细胞
  ↓
点击获得早期 ATP，同时生命开始自动生产
  ↓
购买单轮生产升级，积累 ATP、Biomass、DNA
  ↓
从候选突变中主动选择，改变生产和环境特征
  ↓
达到条件后选择下一物种分支，主谱系进入新阶段
  ↓
环境事件筛选当前物种，适应度决定产出和种群兴衰
  ↓
不断重复成长、突变、分化和环境适应
  ↓
成长放缓时预览 EP，继续积累或主动结束纪元
  ↓
结算 EP，在四条永久强化路线中加点
  ↓
开始新轮，从原始细胞重新演化并保留永久成果
```

没有强制 Game Over。环境危机会造成生产下降和种群损失，但主谱系始终保留最低可恢复种群。玩家可以继续恢复，也可以结束纪元。

## 4. 单轮资源和状态

### 4.1 ATP

- 来源包括点击生命体、物种自动代谢和生产强化。
- 用于购买本轮的基础生产升级。
- 开局阶段点击作用明显，进入自动化阶段后主要依靠物种生产。

### 4.2 Biomass

- 来源为活跃物种的生命活动。
- 用于扩大种群、支付物种分化成本和解锁新阶段。
- 本轮最高 Biomass 里程碑参与 EP 结算。花费 Biomass 不会抹除已经达到的里程碑。

### 4.3 DNA

- 来源为繁殖和世代演化，生产速度低于 ATP 和 Biomass。
- 用于购买主动突变。
- DNA 与跨轮资源 EP 是两种不同资源。DNA 在结束纪元时清零，EP 永久保留。

### 4.4 理念（Knowledge）

- 只有阶段 6 及以上的物种产出理念，产率随种群规模开方增长。
- 理念的唯一用途是购买高阶物种的子升级（每个物种 3 层命名科技）。
- 子升级乘算该物种的全部产率；层级绑定物种编号，谱系分化后旧物种的未购层级即失效。
- 理念不计入 EP；结束纪元时与本轮资源一起清零。

### 4.5 Population

- 每个活跃物种各自拥有种群数量和种群上限。
- 种群越大，该物种对四种资源的贡献越高。
- 环境适应度会改变种群增长或衰减速度。
- 主谱系不会永久降为零。危机后可以通过 Biomass 恢复。

### 4.6 单轮基础升级

单轮提供三类可重复购买的生产升级，用于形成 Cookie Clicker 式的增长循环。

| 升级 | 主要消耗 | 效果 |
| --- | --- | --- |
| Metabolic Efficiency | ATP | 提高 ATP 自动产出和点击收益 |
| Reproductive Capacity | ATP | 提高种群增长和 Biomass 产出 |
| Genome Replication | Biomass | 提高 DNA 产出 |

升级成本随等级增长。具体基础价格和倍率属于平衡参数，可以在测试中调整，不改变玩法和接口。

## 5. 进化树、主谱系和额外分支

### 5.1 主要阶段

完整内容按原方案保留以下阶段。第一版可以减少节点数量，但数据结构必须支持整棵树。

| 阶段 | 代表性内容 |
| --- | --- |
| 原始生命 | 细胞膜、基础代谢 |
| 原核生物 | 光合作用、化学合成 |
| 真核生物 | 细胞核、线粒体 |
| 多细胞生物 | 细胞分化、组织结构 |
| 水生动物 | 感觉器官、运动器官 |
| 陆生动物 | 肺、四肢、角质层 |
| 高级动物 | 恒温、复杂神经系统 |
| 智慧生命 | 高级认知、工具使用，作为长期目标 |

进化树是游戏化的分支结构，不表达现代物种依次由彼此演变的真实历史。

### 5.2 主谱系规则

- 每轮开局只有一个活跃物种，它也是主谱系。
- 达到阶段要求后，玩家在可用后代中选择一个物种。选择会消耗 Biomass，并让主谱系进入下一节点。
- 未选择路线在本轮保持未发现状态，玩家可在后续轮次探索。
- 阶段进度、最高时代和主要结局只由主谱系决定。
- 本轮曾经抵达过的每个不同物种都记入物种发现数，并写入永久图鉴。

### 5.3 多样性强化后的额外分支

- `Diversification Lv.2` 将活跃物种槽从 1 个增加到 2 个。
- 主谱系分化时，玩家可以保留其亲本作为额外分支，或用新分支替换已有的额外分支。
- 额外分支拥有自己的种群和突变，可以生产资源，也会独立接受环境筛选。
- 额外分支不推进主要时代，避免两条完整进化树同时展开造成工作量失控。
- `Diversification Lv.3` 生效后，两个活跃物种的生态标签不同即可获得协同加成。

## 6. 主动突变

### 6.1 触发与选择

- 玩家积累足够 DNA 后主动打开突变选择。
- 系统从当前物种、阶段和前置条件允许的突变池中给出 2 个不重复候选。
- 玩家选择其中 1 个并支付 DNA。未选项以后仍可能再次出现。
- 候选一旦生成就保存到本轮状态。关闭页面、切换页面或读档仍显示同一组候选，不能通过反复打开免费刷新。
- 选择一个突变后，本次候选清除。物种分化或开始新轮时也清除已经失效的候选。
- 已获得的突变不会重复出现。
- `Mutation Lv.3` 将候选数量从 2 个提高到 3 个。

### 6.2 突变的两类效果

每个突变至少包含一个成长效果和一个生物特征，避免突变退化成单纯的百分比升级。

| 效果类型 | 示例 |
| --- | --- |
| 成长效果 | ATP 产出提高、DNA 成本降低、种群上限提高 |
| 环境特征 | 耐热、耐寒、耐缺氧、耐毒、弱光适应 |

突变属于具体物种。结束纪元后，本轮突变清零，图鉴中的发现记录保留。

### 6.3 候选生成规则

- 先按物种、阶段和前置突变过滤不可用项。
- 再按普通和稀有权重抽取候选。
- 不生成重复候选。
- 可用候选不足时显示全部可用项。
- 没有可用突变时按钮置灰并显示原因。

## 7. 环境变化与自然选择

### 7.1 环境事件

环境按时间或阶段触发，一次只存在一个主要事件。事件包括普通变化和环境危机，例如全球降温、温度升高、缺氧、弱光和陨石冲击。

- 普通玩家在事件开始时看到名称、持续时间和影响说明。
- `Adaptation Lv.3` 会提前预览下一事件。
- 同一事件不能连续出现两次。
- 事件结束后恢复常态，再进入下一事件间隔。

### 7.2 自然选择的可见结果

每个物种拥有基础环境特征，突变进一步修改这些特征。环境系统计算适应度，并把结果作用于该物种的种群增长和资源产出。

```text
物种基础适应度
+ 已有突变对当前环境的修正
+ 永久适应强化
= 当前事件中的最终适应度
```

高适应度物种在事件中保持增长或获得生产优势。低适应度物种的增长和生产下降，并可能损失大量种群。界面必须展示每个物种当前适应度、主要加成来源和主要惩罚来源，让玩家能够理解结果。

危机结束时，如果主谱系仍高于该危机开始时种群的一定比例，计为成功度过一次危机。这个比例是可调平衡参数。每个具体危机在同一轮只为 EP 计数一次。

### 7.3 大灭绝

大灭绝是强力环境危机，会按比例削减种群并临时降低生产。它不会删除永久图鉴，也不会强制结束纪元。主谱系保留最低种群，玩家可以恢复或主动结束本轮。

## 8. 纪元结束与 EP 结算

### 8.1 主动结束

- 玩家可在主界面随时打开 End of Era 预览。
- 预览只显示按当前进度可获得的 EP，不改变状态。
- 玩家可以返回本轮继续成长。
- 确认结束后，当前轮冻结，EP 只入账一次，然后进入永久强化页面。
- 当预计到达下一主要节点所需时间过长时，游戏可以提示玩家考虑结束纪元，但不自动执行。

### 8.2 EP 公式

沿用原定公式。

```text
EP = 2E + floor(M / 3) + floor(S / 2) + min(C, 3) + B
```

| 符号 | 含义 |
| --- | --- |
| E | 本轮达到的主要进化阶段数，不含初始阶段 |
| M | 本轮解锁的不同突变数 |
| S | 本轮发现的不同物种数，不按当前存活数量计算 |
| C | 本轮成功度过的不同环境危机数，最多计 6 |
| B | 本轮达到的最高 Biomass 里程碑等级 |

所有里程碑在一轮中只记一次。花费资源、淘汰额外分支、重复触发事件和反复读档都不能重复增加奖励。

## 9. 永久强化树

每条路线最高 5 级，升级成本分别为 1、2、3、4、5 EP。单条路线升满共需 15 EP。玩家可以混合加点，也可以保留未使用 EP。

### 9.1 Metabolism

| 等级 | 永久效果 |
| --- | --- |
| Lv.1 | 基础 ATP 产出 +8% |
| Lv.2 | Biomass 产出 +8% |
| Lv.3 | 新轮获得额外初始 ATP，并提前获得 1 级基础代谢升级 |
| Lv.4 | ATP、Biomass、DNA 产出 +12% |
| Lv.5 | 解锁高级代谢能力节点 |

### 9.2 Mutation

| 等级 | 永久效果 |
| --- | --- |
| Lv.1 | 突变所需 DNA -6% |
| Lv.2 | 再获得 6% 突变成本折扣，总折扣 12% |
| Lv.3 | 每次突变提供 3 个候选，而非 2 个 |
| Lv.4 | 稀有突变候选权重提高 |
| Lv.5 | 解锁特殊突变分支 |

### 9.3 Adaptation

| 等级 | 永久效果 |
| --- | --- |
| Lv.1 | 环境负面影响 -8% |
| Lv.2 | 环境危机持续时间缩短 |
| Lv.3 | 提前预览下一次环境事件 |
| Lv.4 | 环境带来的正面收益提高 |
| Lv.5 | 每轮自动抵挡一次会造成严重种群损失的危机 |

### 9.4 Diversification

| 等级 | 永久效果 |
| --- | --- |
| Lv.1 | 物种种群容量 +10% |
| Lv.2 | 活跃物种槽从 1 个增至 2 个，可以维持额外物种分支 |
| Lv.3 | 不同生态标签的两个活跃物种获得协同加成 |
| Lv.4 | 物种分化所需 Biomass 降低 |
| Lv.5 | 解锁高级演化分支 |

折扣、协同、预览时间和特殊节点的具体数值放在统一平衡表中调整，不在各模块重复硬编码。

## 10. 跨轮保留与重置

| 数据 | 新轮处理 |
| --- | --- |
| ATP、Biomass、DNA、理念 | 重置 |
| 单轮升级、子升级层级 | 重置 |
| 活跃物种和种群 | 重置 |
| 本轮突变、环境和里程碑 | 重置 |
| Evolution Points 余额 | 保留 |
| 四条永久强化等级 | 保留 |
| 已发现物种和突变图鉴 | 保留 |
| 成就和历史最佳记录 | 保留 |

永久强化代表跨轮积累的演化知识和模拟遗产。

## 11. 页面和交互

### 11.1 主游戏页面

- 顶部显示 ATP、Biomass、DNA、理念、EP 余额和当前产速。
- 中部展示当前主谱系生命体、额外分支和环境背景。
- 左侧或下方放置点击区域及三类单轮升级。
- 右侧展示突变候选、物种信息、适应度和当前环境事件。
- 进化树入口展示已走路线、可选下一节点和永久图鉴状态。

### 11.2 End of Era 页面

显示本轮持续时间、最高阶段、突变数、物种数、危机数、Biomass 里程碑和逐项 EP 计算。页面提供返回本轮和确认结束两个操作。

### 11.3 Evolution Legacy 页面

显示 EP 余额、四条永久路线、当前等级、下一级效果和成本。玩家完成加点后开始新轮，未使用 EP 保留。

### 11.4 Codex 页面

显示跨轮发现过的物种、突变和最佳记录。未发现内容显示轮廓或问号，提供长期收集目标。

## 12. 完成目标和内容范围

游戏不以一次失败结束。单轮目标是到达更高阶段并积累更多成果，跨轮目标是填充生命图鉴、解锁永久强化和抵达智慧生命或特殊演化路线。

### 12.1 机制 MVP

机制 MVP 必须完整包含以下内容。

- 点击和四资源自动增长（理念需推进到阶段 6）。
- 三类单轮基础升级。
- 主谱系、至少一个分化选择和物种图鉴记录。
- 主动突变候选与选择。
- 至少两种会产生不同适应结果的环境事件。
- 纪元预览、确认结算、四路永久加点和新轮生效。
- 存档和读档，能够防止重复领取 EP。
- Raylib 主页面、End of Era 页面和 Legacy 页面。

### 12.2 课程最终版目标

- 至少 4 个主要阶段、6 个物种、8 个突变和 4 个环境事件。
- 四条永久强化路线的 5 级效果全部可触发。
- 多样性 Lv.2 的额外分支和 Lv.3 的协同完整可见。
- 图鉴、历史最佳记录和至少 3 个成就。
- 完整阶段表可继续扩充到高级动物和智慧生命，不需要修改核心结构或接口。

## 13. 仍允许调整的内容

以下内容需要试玩后平衡，可以修改数值而不修改机制。

- 资源基础产速、点击收益和升级价格。
- 升级成本倍率。
- 事件持续时间、触发间隔和危机通过阈值。
- 物种基础速率、突变加成、稀有权重和协同百分比。
- Biomass 里程碑门槛。

资源种类（第九轮已由三种扩展为四种，理念见 §4.4）、单轮与跨轮关系、主谱系和额外分支规则、
EP 公式、四条永久强化方向及状态流程视为已冻结设计。

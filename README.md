# Tree of Life

三人 C 语言课程项目，使用 Raylib 2D。采集 ATP、积累生物量和 DNA，选择突变和物种分化，经历环境事件，通过纪元结算获得 EP 与永久强化。

## 统一版本（2026-11-26）

唯一开发分支为 `main`。已汇总 A/B/C、`main-latest` 的第十三轮规则和 `final` 的新版界面；旧分支及重复游戏工程不再保留，提交历史保留在 Git 中。

- A：统一动作入口、固定步、失败回滚、经济、纪元与原子存读档。
- B：186 个物种（阶段 0–13）、204 个突变、20 条共振、14 个环境、30 层子升级、
  4 类随机增益因子与无上限洞见；三个活跃物种槽、8 级永久强化。
- C：培养皿主界面、动态生物形态、星图进化树、图鉴、突变/分化、结算与永久强化页面。
- 最新规则与新版界面共用根目录 `include/game_types.h` 和 `data/balance.h`。容量、储备、跨轮起始奖励及防重复结算保留。
- 当前存档为 v8（3,208 B）；规则细节见 `docs/02-数据与计算规则.md`，B 的 1000 种子验收见 `tree-of-life-b/`。

### 界面补充（2026-11-27）

- **突变图谱**：顶栏「突变」入口 / 物种卡「全部 N >」/ 快捷键 `V` 打开，按物种分栏列出本轮已获得的**全部**突变，底部列出已触发的共振及其两个前置突变。
- **星图进化树**：仍是极坐标星图（一圈一个阶段），重算半径与角度配额把间距拉开；点节点高亮它到原始细胞的整条路线。
- **全中文**：第十三轮遗留的 10 个突变、6 个物种、6 条基石、6 条子升级与 4 条共振名称/描述已译成中文，规则层与适配层的提示语同样是中文。

### 随机因子与洞见（2026-11-27 晚）

- **随机增益因子**：规则层（B）每 45–90 s 刷一个可点击因子，界面现在真的把它画在培养皿里——四个固定方位之一，按 `BUFF_ICON_*` 分四种外观（光球 / 光链 / 气泡 / 星点），带呼吸光环、外扩涟漪与悬停放大。点它（或按 `B`）领取；皿下那行文字会在「因子名称」「增益剩余秒数」「下一个因子约 N 秒」三种状态间切换。
- **限时增益的可视化**：生效期间沿培养皿内壁画一段收短的进度弧，稀有强增益走专属配色；产率增益在 ATP 大数字旁挂 `×1.2 / ×1.5` 胶囊，点击增益则把「采集 +N ATP」改写成带 `×2` 的版本。
- **洞见升格为正式条目**：从 28px 细条改成商店底部的完整卡片，显示等级、`全产率 ×1.06 → ×1.08`、理念价格与「领悟 [7]」；前期理念还没产出时，价格位直接写「阶段 6 起才有理念产出」。顶栏补上第五个资源格「理念」，否则玩家看不到洞见花的是什么。
- **星图可缩放平移**：滚轮以鼠标为锚点缩放 0.75–2.8，空白处按住拖动平移，右上「复位」归位；连线用 scissor 裁在画框内，放大后不会画到标题上。环半径起始值 34 → 48，内圈不再挤成一坨。
- **危机演出**：进入危机的那一帧触发整屏抖屏（陨石 15px / 耀斑 9px / 生态类 4–6px）+ 分类型特效（陨石斜落火痕与冲击波、耀斑放射光条、毒潮绿雾、骤冷冰晶、其余热浪脉冲）+ 2 秒危机标题条，横幅倒计时不被遮挡。
- **图鉴筛选**：物种页只列「已发现 + 相邻（父/子）」，已发现排前面（17 已发现 + 117 相邻 = 12 页，原来是 16 页全量）；突变页只列已收录（23 / 204 收在 2 页）。计数文字分别显示 `已发现 17 / 186 · 相邻 117` 与 `已收录 23 / 204`。

### 生物图像与中文化（2026-11-27 夜）

- **生物图像不出画框**：12 类形态都会在「本体半径」之外再伸出一圈东西（杆菌的荚膜与鞭毛、群体的出芽细胞、行星的环、奇点的吸积盘与喷流），原来只按本体半径排布，杆状菌能长到 2.9r，直接从展台顶到危机横幅上。现在每类形态登记一个外接系数，先按容器可用半径收缩（培养皿按含鞭毛的完整半径、展台/图鉴按实心半径），再用 scissor 硬裁兜底：培养皿、展台三个槽位、图鉴网格、图鉴大图、商店分化缩略图都包在各自的画框里。种群进度环改成按收缩后的半径重算，并画在生物之前，环套在外面不会切线穿过本体。
- **突变与前置条件全中文**：规则表里 `MutationDef` 的 `name` / `description` 是英文（`Lipid Repair`、`A stage-0 adaptation that improves light capture.`），而且同阶段多条突变共用一句模板。名字改用图鉴的 204 条中文名；描述改成按 `MutationDef` 真实数值生成的中文摘要（`阶段 0 · 生物量 +20% · 耐暗 +2`），每一条都说清自己加什么，不再是一句通用英文。

### 说明性界面：扩张作用、星图降噪、路线预告（2026-11-27 深夜）

- **容量 / 储备上屏**：原本只有底栏快捷键 `4 容量 · 5 储备`，界面上没有任何按钮，玩家无法知道它们做什么。商店机能/分化页底部现在并列两张扩张小卡：「4 容量 上限 Lv.N · +X% · 每级 +5%」与「5 储备 减伤 Lv.N · -X% · 每级 -6%」，同时显示 ATP 价格和购买状态。价格与百分比全部转发自规则层，界面不复制公式。
- **星图降噪**：未探索物种不再画成 8px 圆底 + 描边 + 暗色生物（169 个点在十几个环上叠成点阵），改为「前沿」4.2px 生态色小点 + 细环、「远处」2px 暗点；12 条辐射线整组删除、环线压淡；已点亮连线降到 0.26 透明度；标签改成三轮放置（当前/选中 → 选中路线 → 其余），并垫半透明底托，连线不再把名字划花。
- **路线预告**：突变候选卡与分化候选卡都多一行「后续」，选之前就能看到这条路会解锁什么。适配层倒查「前置突变 → 物种 → 主干子代」两步，输出全中文，例如「解锁 化能细菌 → 原生捕食者 → 简单多细胞群落」；纯数值突变写「纯数值强化 · 不单独解锁分化路线」。两个弹层的卡高同步调整，4K 截图已逐张核对无越界。

## 构建与运行

Windows 下安装 MinGW-w64 GCC、mingw32-make 和 Python，并加入 PATH：

```powershell
.\build.ps1                # 规则测试、集成测试、60 分钟回归、游戏构建
.\treeoflife.exe
# 或双击 build.bat
```

首次构建下载 raylib 5.5 官方开发库到 `.local/deps/` 并静态链接。中文字体从本机 Windows 等线复制到 `assets/fonts/`，不提交 Git，仅供本地课程演示；公开分发前请替换为允许再分发的字体。

```powershell
mingw32-make test          # 三组真实规则/集成回归，无测试替身
mingw32-make test-ui       # 真实点击入账与界面飘字一致性
mingw32-make demo          # 可选的规则实验控制台
mingw32-make dist          # 单文件版：资源编进 exe → dist/TreeOfLife.exe
.\treeoflife.exe --shot --ss 3  # 25 张 3840×2160 演示截图
```

### 单文件版（免安装、不用旁边的资源目录）

`mingw32-make dist` 产出 `dist/TreeOfLife.exe`（约 22 MB）：用 `objcopy -I binary` 把
`assets/` 里的等线字体、两张纹理、三个音效编成目标文件链进可执行文件，运行时由
`src/embedded.c` 从内存解码（`LoadFontFromMemory` / `LoadImageFromMemory` /
`LoadWaveFromMemory`），并用 `-static -static-libgcc` 静态链接 raylib 与 GCC 运行时。
拷到任何目录双击即可开玩，只依赖系统自带的 user32/gdi32/opengl32 等 DLL。

普通构建（`mingw32-make`）不带 `-DEMBED_ASSETS`，`emb_get()` 恒返回 false，仍按
`assets/` 相对路径读盘 —— 开发期换图、换字体立刻生效，不用重编内嵌数据。

截图模式使用人工构造的中后期局面，正常新游戏从原始细胞和零资源开始。程序启动时把工作目录切到可执行文件所在目录，资源与 `saves/` 都相对它；统一存档路径为 `saves/treeoflife-v8.sav`，早期存档不自动迁移或覆盖。

## 操作

鼠标操作培养皿、商店和各页面。空格采集；1/2/3 单轮升级；4 容量、5 应急储备、6 主谱系科技；M 打开突变面板（抽候选）、V 突变图谱（本轮已获得的全部突变）、E 结算、C 图鉴、T 星图、Tab 商店切换、Esc 关闭弹层、F11 全屏。星图里点任意节点会高亮它到原始细胞的整条分化路线，再点一次取消。字母快捷键建议使用英文输入法。

## 目录与交付

- `src/`、`include/`、`data/`：唯一游戏源码、公共接口和平衡数据。
- `tests/`：最新 B 规则测试、A+B 接线测试、完整集成回归。
- `assets/`：运行资源；`.local/deps/`：本机构建依赖；`saves/`：用户存档。
- `docs/`：设计说明和美术说明；`tree-of-life-b/`：队友规则研究报告，历史实验不代表当前整合版的平衡结论。
- `demo/`、`tools/reports/`：规则实验入口及报告生成源脚本。报告生成依赖的实验 CSV 需在脚本同目录重新生成。
- `deliverables/Tree-of-Life/`、`deliverables/Tree-of-Life-20261126.zip`：当前统一试玩版。
- `deliverables/screens/`：本轮统一版 25 张截图（含随机因子、增益状态、星图降噪、陨石危机、路线预告与扩张卡）。
- `AGENTS.md`、`WORK_LOG.md`：持续工作规则和可核实进度。

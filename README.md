# Tree of Life

三人 C 语言课程项目，使用 Raylib 2D。采集 ATP、积累生物量和 DNA，选择突变和物种分化，经历环境事件，通过纪元结算获得 EP 与永久强化。

## 统一版本（2026-11-26）

唯一开发分支为 `main`。已汇总 A/B/C、`main-latest` 的第十三轮规则和 `final` 的新版界面；旧分支及重复游戏工程不再保留，提交历史保留在 Git 中。

- A：统一动作入口、固定步、失败回滚、经济、纪元与原子存读档。
- B：264 个物种（阶段 0–13）、282 个突变、29 条共振、14 个环境、30 层子升级、
  4 类随机增益因子与无上限洞见；三个活跃物种槽、8 级永久强化。
- C：培养皿主界面、动态生物形态、星图进化树、图鉴、突变/分化、结算与永久强化页面。
- 最新规则与新版界面共用根目录 `include/game_types.h` 和 `data/balance.h`。容量、储备、跨轮起始奖励及防重复结算保留。
- 当前存档为 v10（3,952 B）；规则细节见 `docs/02-数据与计算规则.md`，B 的 1000 种子验收见 `tree-of-life-b/`。

### 随机因子与洞见（2026-11-27 晚）

- **随机增益因子**：规则层（B）每 45–90 s 刷一个可点击因子，界面现在真的把它画在培养皿里——四个固定方位之一，按 `BUFF_ICON_*` 分四种外观（光球 / 光链 / 气泡 / 星点），带呼吸光环、外扩涟漪与悬停放大。点它（或按 `B`）领取；皿下那行文字会在「因子名称」「增益剩余秒数」「下一个因子约 N 秒」三种状态间切换。
- **限时增益的可视化**：生效期间沿培养皿内壁画一段收短的进度弧，稀有强增益走专属配色；产率增益在 ATP 大数字旁挂 `×1.2 / ×1.5` 胶囊，点击增益则把「采集 +N ATP」改写成带 `×2` 的版本。
- **洞见升格为正式条目**：从 28px 细条改成商店底部的完整卡片，显示等级、`全产率 ×1.06 → ×1.08`、理念价格与「领悟 [7]」；前期理念还没产出时，价格位直接写「阶段 6 起才有理念产出」。顶栏补上第五个资源格「理念」，否则玩家看不到洞见花的是什么。
- **星图可缩放平移**：滚轮以鼠标为锚点缩放 0.75–2.8，空白处按住拖动平移，右上「复位」归位；连线用 scissor 裁在画框内，放大后不会画到标题上。环半径起始值 34 → 48，内圈不再挤成一坨。
- **危机演出**：进入危机的那一帧触发整屏抖屏（陨石 15px / 耀斑 9px / 生态类 4–6px）+ 分类型特效（陨石斜落火痕与冲击波、耀斑放射光条、毒潮绿雾、骤冷冰晶、其余热浪脉冲）+ 2 秒危机标题条，横幅倒计时不被遮挡。

### 生物图像与中文化（2026-11-27 夜）

- **生物图像不出画框**：12 类形态都会在「本体半径」之外再伸出一圈东西（杆菌的荚膜与鞭毛、群体的出芽细胞、行星的环、奇点的吸积盘与喷流），原来只按本体半径排布，杆状菌能长到 2.9r，直接从展台顶到危机横幅上。现在每类形态登记一个外接系数，先按容器可用半径收缩（培养皿按含鞭毛的完整半径、展台/图鉴按实心半径），再用 scissor 硬裁兜底：培养皿、展台三个槽位、图鉴网格、图鉴大图、商店分化缩略图都包在各自的画框里。种群进度环改成按收缩后的半径重算，并画在生物之前，环套在外面不会切线穿过本体。

### 生境演替：大环境随时代更换（2026-11-28）

- **问题**：阶段 0–7 都在水里，可阶段 6 之后生物已经上岸（森林 / 城市 / 轨道 / 奇点），展台却一直是同一块深水底，玩家读不出「离开海洋多久了」。
- **8 种生境**（`include/habitat.h`）：深海热泉（阶段 0–1）→ 透光浅海（2–3）→ 珊瑚礁（4–5）→ 湿地与森林（6–7）→ 城市与技术圈（8–9）→ 轨道与深空（10）→ 奇点与星云（11），另有极地冰海给耐寒旁支。
- **判定先看名字，再看阶段**：v14 的 264 个物种里有「深海化能鱼」「极地苔原」「菌藻地衣」这类跨阶段旁支，只按阶段会套错背景。`habitat_for_species()` 依次匹配中文名里的「深海/热泉/化能」「礁/珊瑚」「极地/苔原/冰」「森林/湿地/地衣」「城/蜂群/文明」「轨道/戴森/恒星」「奇点/超越」，没有线索才回落到阶段。
- **画法**：每种生境只有三种材料——竖直渐变（底色）、地形剪影（热泉烟囱、礁脊、冰山、树线、楼群、行星弧）、粒子（气泡上浮、雪下落、孢子呼吸、星尘外扩）。粒子位置只由时间取模推进，静止时完全可复现；边缘 15px 渐隐，生境融进面板圆角。
- **四处共用一套**：展台（标题旁多一个生境 chip，如「城市与技术圈」）、图鉴大图（底部写「物种图鉴 · 湿地与森林」）、培养皿（液体与沉积跟着生境换色，不再是永恒的海水蓝）、全屏上下边缘的极淡环境色晕（≤0.055 alpha，不压中心）。
- **横幅不再一律写「常态海洋」**：常态期且生境已上岸时，横幅显示「常态 · 湿地与森林」并换成该生境的说明；危机 / 丰饶事件仍用规则层原名。
- **顺手修掉一个内容扩容 bug**：`ecology_color()` 的手工色板只有 20 项，v14 扩到 264 个物种后，后 244 个物种取到的是 alpha=0 的透明黑，图鉴里过半生物会「消失」。现在主线 20 个保留原色，其余按「阶段基色 + id 抖动」派生，既有稳定色相又不会全透明。
- **产物**：`shot_11_habitats.png`（8 格生境样张，一张图核对每个阶段站在什么地上）与 `shot_04d_codex_habitat.png`（图鉴大图里的湿地背景）；本轮 4K 截图 25 → 27 张（其后追加两张滚轮样张、一张长文案样张、两张纪元封顶样张与一张星图同阶段旁支样张，共 33 张）。

### 突变图谱：滚轮查看全部（2026-11-28 下午）

突变图谱原本每栏固定 3 列 × 4 行 = 12 格，晚期的物种（例如文明带 20 项以上突变）会被截在「还有 N 项」上，玩家没法核对第 13 项以后到底拿了什么。

- **滚轮翻本栏**：鼠标放到哪一栏，滚轮就翻哪一栏——两栏并排时不会把另一栏一起滚走。一格一行，两侧边缘各加 12px 渐隐，暗示上下还有内容。
- **滚动条**：格子装不下时，栏内右缘出现 4px 轨道 + 滑块，滑块位置就是 `scroll / max_scroll`；表头同时把「N 项突变」补成「N 项突变 · 滚轮看全部」。
- **装得下就不滚**：内容 ≤ 12 项时 `max_scroll = 0`，滚轮在该栏完全无效，不会出现「滚了但什么都没动」的空转感。
- **裁剪兜底**：滚动中的格子会越出网格区，绘制前用 `ui_clip_begin(grid)` 硬裁，压不到下面的表头和共振条。
- **几何只有一份**：栏位布局与网格区（`mut_list_layout` / `mut_box_rect` / `mut_grid_rect`）由绘制和滚轮命中共同调用，`screens_mut_list_scroll_target()` 返回 `{slot, row_h, max_scroll}`，`ui.c` 只按这三个值改 `g_ui.mut_scroll[slot]`，不复制任何布局常量。
- **产物**：`shot_05d_mut_scroll.png`（21 项停在顶部）与 `shot_05e_mut_scroll_end.png`（滚到底，滑块贴底），4K 逐张核对无溢出；`make test-layout` 新增命中测试（第一栏可滚 78px、第二栏不可滚、表头与面板外不命中）。

### 纪元阶段上限：到顶了要说清（2026-11-28 夜）

规则层有一条容易被忽略的硬约束：**v8 P0-17 给每个纪元压了阶段深度上限，纪元 1 = 阶段 8、纪元 2 = 阶段 10、纪元 3 起 = 阶段 13（即全表最高阶段，等于不再限制）**。到顶之后 `evolution_validate_speciation` 直接返回 `ACTION_REQUIREMENT_NOT_MET`，只能结算进入下一纪元，横向支线也走不了——因为分化目标一律是下一阶段的物种。

- **问题**：界面把这条约束显示成了「前置不足」。玩家在纪元 1 打到文明（阶段 8）时，四张分化卡全写着「前置不足」，而前置突变其实早买齐了，于是会去堆突变、堆生物量，怎么都点不动。
- **五处上屏**（数字全部来自规则层，界面不写 8/10/13）：
  · 顶栏纪元牌：到顶时右侧出现红字「封顶」，底部那条演化进度改用「本纪元上限」做分母并转红——原来的 12 阶分母会让纪元 1 到顶时只走到 8/11，看着像「还没爬完」，跟规则正好相反。
  · 分化弹层：标题下多一行「第 N 纪元上限：阶段 X · 已到顶，本轮不会再出现可分化方向，结算进入下一纪元才能继续上行」；未到顶时写「还能再走 K 阶」。
  · 分化候选卡：越界的目标不再说「前置不足」，改写「超出本纪元上限 N · 结算进入下一纪元」，右侧状态是「本纪元封顶」。
  · 商店分化卡与底栏「物种分化」按钮：「超出本纪元上限 N」/「本纪元已封顶」，玩家在点开弹层之前就知道为什么点不动。
  · 结算页右上角：「本纪元上限 阶段 N · 还能再走 K 阶」（到顶写「已封顶」）；底部旁白在到顶时也改写，不再说「演化还在缓慢积累」。
- **适配层只转发**：新增 `ua_era_stage_cap()` / `ua_main_stage()` / `ua_speciation_era_capped()`，前者转发 `evolution_era_stage_cap`，后者只是把「目标阶段 > 本纪元上限」这条分类判断拿出来（判定本身仍走 `evolution_validate_speciation`，那条检查排在支线深度与前置突变之前，所以「判定失败 + 分类为真」唯一原因就是封顶）。
- **产物**：`shot_03b_speciation_cap.png`（纪元 1 停在阶段 8，前置与生物量都给满，四张卡全封顶）与 `shot_01i_era_cap.png`（主界面：纪元牌「封顶」+ 底栏副标题）；`make test-layout` 新增 `test_era_stage_cap`——上限随纪元走、分类与规则层判定不矛盾、封顶时四张卡全灰、换到纪元 2 后同一批候选恢复可点。

### 星图：同阶段旁支也要有连线（2026-11-28 夜）

- **现象**：藻类真核生物 → 光合菌席、简单多细胞群落 → 几丁质礁、智慧生命 → 蜂群政体……这类「同一时代分出去的一支」在星图上没有连线，两个节点画在同一圈却像互不相干。
- **原因**：连线循环里有一句 `parent phase >= child phase 就跳过`，本意是挡「晚 → 早」的反向边，却把同阶段父子一起挡掉了。规则层的 264 个物种里这种父子对共 **35 对**。
- **改法**：只挡反向边；同阶段的两端改画**沿本圈椭圆走的弧线**（`tree_arc`），跨阶段仍是原来那条向圆心收 14% 的贝塞尔弦。弧线半径同样乘 zoom（否则放大后弧会缩在圈内、末端接不到节点），段数随弧长自适应（8–40 段），隔大半圈的两个节点不会画成折角。
- **图例**：顶部说明补上「同圈弧线 = 同阶段旁支」，玩家不用猜两种线的区别。
- **产物**：`shot_05f_tree_same_phase.png`——选中「几丁质礁」，整条来路高亮，最后一跳（简单多细胞群落 → 几丁质礁）是一条贴圈的弧，两端都落在节点上；`make test-layout` 新增 `test_tree_same_phase_edges`（锁住 35 对同阶段父子，防止以后又被当成反向边过滤掉）。

### 说明性界面：扩张作用、星图降噪、路线预告（2026-11-27 深夜）

- **容量 / 储备上屏**：原本只有底栏快捷键 `4 容量 · 5 储备`，界面上没有任何按钮，玩家无法知道它们做什么。商店机能/分化页底部现在并列两张扩张小卡：「4 容量 上限 Lv.N · +X% · 每级 +5%」与「5 储备 减伤 Lv.N · -X% · 每级 -6%」，同时显示 ATP 价格和购买状态。价格与百分比全部转发自规则层，界面不复制公式。
- **星图降噪**：未探索物种不再画成 8px 圆底 + 描边 + 暗色生物（169 个点在十几个环上叠成点阵），改为「前沿」4.2px 生态色小点 + 细环、「远处」2px 暗点；12 条辐射线整组删除、环线压淡；已点亮连线降到 0.26 透明度；标签改成三轮放置（当前/选中 → 选中路线 → 其余），并垫半透明底托，连线不再把名字划花。
- **路线预告**：突变候选卡与分化候选卡都多一行「后续」，选之前就能看到这条路会解锁什么。适配层倒查「前置突变 → 物种 → 主干子代」两步，输出全中文，例如「解锁 化能细菌 → 原生捕食者 → 简单多细胞群落」；纯数值突变写「纯数值强化 · 不单独解锁分化路线」。两个弹层的卡高同步调整，4K 截图已逐张核对无越界。

### 生物美术重制：标本摄影风（第 18 版，2026-11-27 夜）

- **19 张形态插画全部重画**：`assets/tex/morph/` 下 19 个形态族（球菌 / 杆菌 / 真核细胞 / 细胞群体 / 分化组织 / 共生体 / 神经网 / 技术圈 / 硅藻 / 草履虫 / 变形虫 / 丝状藻 / 菊石 / 早期鱼类 / 水母 / 蕨类 / 真菌 / 珊瑚 / 蜂巢）改由 Seedream 5.5 重新生成，统一到「透射显微 + 标本棚拍」的写实方向：主光固定在左上 45°、透明底完全镂空、主体居中、禁止糖果玻璃质感与霓虹光晕。上一版偏暖橙的「CG 感」和像玻璃弹珠的球菌、像果冻的真核细胞都被替换掉。
- **统一取景归一化**：新增 `tools/normsprites.c`（`tools/normsprites.exe 0.86 1536 <png...>`）。原图主体经常顶到画布边缘（菌丝、蜂巢、神经网最明显），图鉴里会被削成方块、展台上还会压住旁边的物种名。工具按 alpha 包围盒裁紧、等比缩到画布 86% 内居中、四周补透明边，采样用逐通道双线性（不预乘），半透明膜与触手不会压黑。原始图留在 `docs/art/morph_raw/`，上一版留档在 `docs/art/morph_v17_backup/`。

## 常见疑问：容量只买到 4 级、物种只见到 54 个

这两条是规则层 v19 定稿后**记录在案的取舍结果**，不是没做完，也不是 bug。

**容量为什么停在 4 级（上限 26）。** 容量是 ATP + 生物量双币：ATP 半边 `80 s 产率 × 1.06^级`，生物量半边只要 `10 s 产率`。但买容量之前必须给分化门票留出生物量——预演策略会预留约 0.55 张门票的量（`speciation_biomass_reserve_for(0.55)`）。这条预留不是保守，而是实测回归：放开预留后，阶段 8 抵达率从 98% 掉到 27%。也就是说容量的瓶颈不是价格，而是「横向扩张」和「纵向分化」在抢同一份生物量；把产能全投进容量，主线就爬不动了。校准结果就是 4 级容量 + 12–13 次分化。

**物种为什么只看到 54/264（1000 局三批并集）。** 单局物种数被两条规则夹住：每局 16–18 个（G4 验收区间），支线离主链最多 2 层（`BRANCH_MAX_DEPTH 2`，每个支线槽位最多 2 次分化）。活跃槽位默认 2 个（`Diversification Lv.5` 才扩到 3 个），主链 12–13 个加上支线各 2 次，正好落在 17 上下。把深度放宽到 3，单局就会冲破 18 并连锁破坏阶段与支出率门槛，所以这是结构性上限。264 个物种分布在 12 个阶段与多条旁支上，单局只能走其中一条分支，其余靠多局、跨轮累积去收集。阶段 13（抵达 2.1%）本身是彩蛋区，靠突变稀有度而不是主线保底，不进门槛。
